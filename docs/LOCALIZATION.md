# Русификация

## Два слоя

### Клиент

Клиент рисует текст из двух источников:

1. **Cliloc** — таблица строк, которую присылает сервер и которую клиент
   использует для названий предметов, свойств, умений, подсказок. Файл
   `Cliloc.enu` лежит в папке клиента.
2. **Пакеты сервера** — системные сообщения и речь NPC. POL отправляет их
   в кодировке UTF-8; если в строке есть не-ASCII символы, ядро автоматически
   использует Unicode-пакет (0xAE). Клиент рисует их юникодным шрифтом
   (`unifont*.mul`).

В используемом клиенте `unifont.mul` уже содержит кириллицу (92 глифа
в диапазоне U+0400–U+04FF), поэтому отдельная генерация шрифта не нужна.

### Сервер

Тексты находятся в:

- `server/scripts/**/*.src`, `server/pkg/**/*.src` — сообщения, диалоги;
- `server/config/*.cfg`, `server/pkg/**/config/*.cfg` — имена и описания
  NPC, предметов, книг, табличек;
- `server/pkg/utils/clilocs/config/clilocs.cfg` — таблица cliloc-строк,
  используемая `SendSysMessageCL`.

POL 100 сам определяет UTF-8 в `SendSysMessage`, `Say`, `PrintTextAbove`
(`hasUTF8Characters`), поэтому переводить можно прямо в `.src` без вызовов
`SendSysMessageUC`.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `tools/extract_strings.py` | строит `locale/ru/catalog.json` — все литералы с файлом и строкой |
| `tools/apply_translation.py` | применяет JSON-словарь к литералам, не трогая комментарии |
| `tools/build_cliloc_ru.py` | собирает `Cliloc.rus` из бинарного перевода или JSON |

### Порядок работы

```bash
python3 tools/extract_strings.py                    # обновить каталог
python3 tools/apply_translation.py locale/ru/phrases.json --dry-run
python3 tools/apply_translation.py locale/ru/phrases.json
./scripts/compile-scripts.sh                        # проверить компиляцию
```

### Важно

- **Ключевые слова речи NPC** (`sell all`, `vendor train`, `guards!`) — это
  команды, а не текст. Их нельзя переводить вслепую: сломается диалог.
  Для русских команд нужно добавлять алиасы в обработчики.
- Строки, которые используются как ключи свойств (`lastlogon`, `#equipped`),
  переводить нельзя.
- Динамические сообщения собираются конкатенацией. Переводить нужно каждый
  фрагмент целиком, сохраняя пробелы и порядок.
- После массового перевода обязательна перекомпиляция: `ecompile` покажет
  синтаксические ошибки, если перевод случайно задел код.
