# Статус проекта

Обновлено: 2026-10-29

## Хронология

1. Ядро POL 100.2.0 склонировано и собрано под CachyOS (GCC 16, C++20).
   - Понадобились два локальных патча сборки (см. `patches/`):
     - `USE_BOOST_HEADER_STACKTRACE=ON` и отключение `-lbacktrace` — в системе нет libbacktrace;
     - сборка curl без libssh2 — иначе статическая libcurl требует libssh2.
2. Развёрнут ModernDistro в `server/`.
3. Клиентские файлы (7.0.x, MUL) скопированы в `client/` из старой установки.
4. Мир Британия сконвертирован: `uoconvert` для multis/tiles/landtiles, map `7168x4096`, statics, maptile.
   - Только Фелукка: в клиенте нет карт Илшенара, Маласа, Токуно и Тер-Мура.
   - Из `regions.cfg`, `startloc.cfg` и `itemdesc` удалены/отключены определения,
     которых нет в клиентских данных (14 регионов, 10 стартовых точек, 888 записей itemdesc,
     7 мульти).
5. Установлены модули eScript из `pol-core/support/scripts`, создан `ecompile.cfg`,
   все скрипты скомпилированы (0 ошибок).
6. Сервер запускается, слушает `2593`. ClassicUO подключается, создаёт персонажа.
7. Проверена кириллица: два сообщения переведены, POL отправил их Unicode-пакетом,
   клиентский журнал сохранил русский текст без искажений.
8. Собран `client/Cliloc.rus` (7 418 строк) из перевода сообщества UOGames (7.0.86).
   ClassicUO загружает его поверх английского `Cliloc.enu`.

## Что работает

- Вход в игру, создание персонажа, мир Британия.
- Административная учётка `admin` / `admin`.
- Веб-консоль POL на `http://127.0.0.1:5006`.
- Русские сообщения сервера (UTF-8).
- Частичный русский клиентский текст: свойства, названия предметов, часть интерфейса.

## Известные проблемы

- Клиентский UI (кнопки, окна создания персонажа) в основном английский:
  текст вшит в графику gump'ов, для полного перевода нужна замена gump-арта
  или доработка ClassicUO.
- `Cliloc.rus` покрывает 7 418 из ~49 700 строк клиента.
- Часть скриптов ссылается на отсутствующие файлы (`mooringLine.ecl`,
  `housetele.ecl`) — предупреждения при старте, на игру не влияют.
- Сообщение `TS_StartController() - Controller is already running` — безвредный
  варнинг из скриптов.
- Имя сервера в списке — латиницей (`Russian Shard`). Кириллица в пакете
  списка серверов требует проверки.
- Полный список отсутствующих графики/мульти можно получить, сравнив itemdesc
  с `config/tiles.cfg`.

## Как проверить

```bash
./scripts/run-server.sh        # в отдельном терминале
./scripts/run-client.sh        # логин admin / admin
```

Журнал клиента: `clientapp/Data/Client/JournalLogs/`.
Лог сервера: `logs/pol.log` (при запуске через systemd/скрипт).
